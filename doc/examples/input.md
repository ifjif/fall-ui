# input组件

:::demo inputType属性指定主题，可选值：primary(默认)、success、warning、error

```html
input/index
```

:::
:::demo placeholder属性，指定提示词

```html
input/placeholder
```

:::
:::demo width属性，设置input宽度

```html
input/width
```

:::
:::demo clear属性，展示清除图标,可清除输入框中的文本

```html
input/clear
```

:::
:::demo show-password属性，使输入框成为密码框(不会显示原始输入内容，而是某个占位符代替内容显示)

```html
input/show-password
```

:::
:::demo maxlength属性,限制输入框中的字符数量

```html
input/maxlength
```

:::
:::demo count属性，展示输入字符数量，前提条件是必须设置maxlength

```html
input/count
```

:::
:::demo disabled属性, 输入框禁用

```html
input/disabled
```

:::
:::demo 前缀和后缀

```html
input/prefix-suffix
```

:::
:::demo 前置和后置

```html
input/prepend-append
```

:::
