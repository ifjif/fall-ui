# container组件

:::demo 使用

```html
container/index
```

:::
使用以下组件：
fl-container: 代表整个布局，它默认占满父容器
fl-main: 代表布局中的 body，它占满布局中的剩余部分
fl-header: 代表布局中的 header，您需要设置高度 它的属性 height
fl-footer: 代表布局中的 footer, 您需要设置高度 它的属性 height
fl-aside: 代表布局中的 侧边部分，您需要设置宽度 它的属性 width
在fl-container中可以继续 包含 fl-container来满足您的复杂布局
:::demo 示例布局1

```html
container/con1
```
